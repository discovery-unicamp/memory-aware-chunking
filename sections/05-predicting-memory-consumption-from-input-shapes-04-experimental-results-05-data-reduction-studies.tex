\subsection{Data Reduction Studies}
\label{subsec:pmc-results-data-reduction-studies}

This section evaluates the impact of training set size on model performance.
The goal is to determine how many samples are needed to reliably learn the shape-to-memory mapping, especially under the volume-centric assumption.

Experiments progressively subsample the dataset, keeping only the smallest and largest volumes and removing middle-range configurations.
Models used are the same as in prior sections: Gradient Boosting (Envelope), Decision Tree (\ac{GST3D}), and Linear Regression (Gaussian Filter).

\label{subsec:data-reduction-strategy-and-motivation}

\subsubsection{Conclusions on Data Pruning}
\label{subsec:data-reduction-conclusions}

Thirty to forty samples per operator reliably yield accurate peak‐memory predictions under volume‐centric assumptions, reflecting a strong balance between dataset size and model performance.
Volume extremes provide valuable learning signals, but including a modest range of middle‐volume configurations enhances stability, especially for \ac{GST3D}, which exhibits greater sensitivity to severe down‐sampling.
Envelope and Gaussian Filter models remain robust with fewer data points, demonstrating resilient predictive power even under aggressive sample reduction.
These findings confirm that moderate data pruning offers a practical path to deploying memory estimators in scenarios with limited training data while preserving the accuracy required for real‐world applications.
